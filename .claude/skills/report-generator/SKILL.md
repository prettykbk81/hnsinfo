# 업무 보고서 자동 생성기

홈앤쇼핑 임직원을 위한 업무 보고서 자동 생성 스킬입니다.

## 사용 시점

- 사용자가 "보고서 만들어줘", "주간보고 작성해줘", "회의록 정리해줘" 등을 요청할 때
- 사용자가 `/report-generator`를 호출할 때

## 입력 수집

사용자에게 아래 정보를 확인합니다 (제공되지 않은 항목만 질문):

1. **보고서 유형**: 주간업무보고 / 월간실적보고 / 기획보고 / 회의록 정리 / 업무 인수인계서
2. **보고 대상**: 팀장 / 실장·부서장 / 임원 / 경영진
3. **보고 기간**: 예) 2026.06.16 ~ 06.20
4. **부서/팀**: 예) 영업기획팀
5. **핵심 내용**: 키워드, 메모, 회의 내용 등 (자유 형식)

## 보고서 작성 규칙

아래 규칙을 반드시 따릅니다:

- **보고 대상에 맞는 톤**: 팀장에게는 실무적, 임원/경영진에게는 전략적·요약적
- **한국 대기업/홈쇼핑 회사 보고서 형식** 준수
- 수치가 있으면 **전주/전월 대비 변화율** 포함하여 강조
- 마지막에 반드시 **"향후 계획"** 또는 **"요청사항"** 섹션 포함
- 불필요한 인사말 없이 **바로 본론으로**
- **제목 → 소제목 → 번호** 구조로 읽기 쉽게 구성
- 홈앤쇼핑 맥락 반영 (홈쇼핑, 라이브커머스, 방송 편성, MD 업무 등)

## 보고서 유형별 템플릿

### 주간업무보고
```
[부서명] 주간업무보고 (기간)

1. 금주 실적 요약
2. 주요 추진 업무
3. 이슈 및 조치사항
4. 차주 계획
5. 요청사항
```

### 월간실적보고
```
[부서명] 월간실적보고 (기간)

1. 월간 실적 총괄 (목표 대비 달성률)
2. 채널별/카테고리별 실적
3. 전월 대비 증감 분석
4. 주요 성과 및 이슈
5. 익월 목표 및 전략
```

### 기획보고
```
[보고 제목]

1. 추진 배경 및 목적
2. 현황 분석
3. 추진 방안 (세부 실행 계획)
4. 기대 효과
5. 일정 및 소요 자원
6. 검토 요청사항
```

### 회의록 정리
```
[회의 제목] 회의록

일시:
참석자:
안건:

1. 논의 내용 요약
2. 결정 사항
3. 액션 아이템 (담당자, 기한)
4. 차기 회의 일정
```

### 업무 인수인계서
```
[담당 업무] 인수인계서

1. 업무 개요
2. 주요 업무 내용 (항목별 상세)
3. 진행 중인 업무
4. 정기 업무 스케줄
5. 주요 연락처 및 시스템 접근 정보
6. 유의사항
```

## 출력 형식

- 완성된 보고서를 마크다운 형식으로 출력
- 사용자가 복사하여 바로 사용할 수 있는 수준으로 완성
- 보고서 끝에 `---` 구분선 후 "이 보고서는 AI가 초안을 작성했습니다. 내용을 검토 후 사용하세요." 안내 추가
