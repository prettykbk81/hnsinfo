왜 Cloudflare Worker가 필요한가?
브라우저는 보안 정책(CORS)으로 인해 api.notion.com을 직접 호출할 수 없습니다. Cloudflare Worker가 중간에서 요청을 대신 전달하는 프록시 역할을 합니다. 무료 플랜으로 충분합니다.
STEP 1 — Cloudflare Worker 배포
1
Cloudflare 가입 후 Workers & Pages 이동
workers.cloudflare.com → Create Worker → 아무 이름 입력 (예: notion-proxy)
2
아래 코드를 붙여넣고 Deploy
Edit code → 기존 코드 전체 삭제 → 아래 코드 붙여넣기 → Save and Deploy
addEventListener('fetch', event => {
  event.respondWith(handleRequest(event.request));
});

async function handleRequest(request) {
  if (request.method === 'OPTIONS') {
    return new Response(null, {
      headers: {
        'Access-Control-Allow-Origin': '*',
        'Access-Control-Allow-Methods': 'GET,POST,PATCH,DELETE,OPTIONS',
        'Access-Control-Allow-Headers': 'Authorization,Content-Type,Notion-Version',
      }
    });
  }
  const url = new URL(request.url);
  const target = 'https://api.notion.com' + url.pathname + url.search;
  const reqHeaders = new Headers(request.headers);
  reqHeaders.delete('host');
  const resp = await fetch(target, {
    method: request.method,
    headers: reqHeaders,
    body: ['GET','HEAD'].includes(request.method) ? null : await request.text(),
  });
  const resHeaders = new Headers(resp.headers);
  resHeaders.set('Access-Control-Allow-Origin', '*');
  return new Response(await resp.text(), { status: resp.status, headers: resHeaders });
}

▼
1목표 — Claude가 만들고 싶은 것

홈쇼핑 MD·SNS 운영자가 상품명 + 특징만 입력하면 인스타그램 카드뉴스 제목 3종, 이모지 캡션, 해시태그, 방송 오프닝을 Claude API가 5초 안에 생성하고, Notion 데이터베이스에 자동 저장되는 브라우저 기반 원스톱 도구를 만든다.

서버 없이 HTML + JavaScript만으로 동작 → GitHub Pages 배포 → GitHub Actions로 push하면 자동 배포. 바이브코딩으로 하루 완성 가능한 실용 도구.

2주요 사용자
홈앤쇼핑 MD (핵심) SNS 운영팀 방송 작가 · PD 파트너사 마케터 바이브코딩 배우는 누구나
