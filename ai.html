HomeShopping AI Copy Maker · PRD v1.0

MVP · 1일 완성
1목표 — Claude가 만들고 싶은 것

홈쇼핑 MD·SNS 운영자가 상품명 + 특징만 입력하면 인스타그램 카드뉴스 제목 3종, 이모지 캡션, 해시태그 세트, 방송 오프닝 멘트를 5초 안에 생성해주는 브라우저 기반 도구를 만든다.

서버 없이 HTML + JavaScript만으로 동작해, 배포도 GitHub Pages 한 방이면 끝난다. 바이브코딩으로 하루 안에 완성할 수 있는 가장 실용적인 도구.

2주요 사용자
홈앤쇼핑 MD (핵심) SNS 운영팀 방송 작가 · PD 파트너사 마케터 바이브코딩 배우는 누구나

Claude가 제안하는 확장 사용자: 카피라이팅을 배우는 인턴, 상세페이지 초안이 필요한 협력사, 방송 스크립트 작업이 반복되는 작가까지. 카피 업무가 있다면 누구든 쓸 수 있다.

3핵심 기능 (MVP 4개)
01
카드뉴스 제목 3종 생성
카테고리별 패턴으로 임팩트 있는 제목 3가지를 한 번에 제안
02
인스타 캡션 + 해시태그
이모지 포함 캡션 + 카테고리 맞춤 해시태그 20개 자동 생성
03
방송 오프닝 멘트
카테고리·분위기별 오프닝 멘트 1종 생성 (재생성 버튼)
04
원클릭 복사
각 결과물 옆 복사 버튼 → 클립보드 즉시 복사, 완료 표시
4이번 버전에서 제외 (Out of Scope)

아래는 제외하지만 Claude가 교육 내용을 기반으로 더 만든다면 언제든 확장 가능 —

실제 AI API 연동 (Claude API) 자동 인스타그램 포스팅 이미지 자동 생성 (DALL·E) 상품 DB 연동 로그인·사용자 관리

💡 Day 2~3 교육 이후라면: Claude API 연동으로 진짜 AI 카피 생성, Notion MCP로 결과 자동 저장, GitHub Actions로 자동 배포까지 확장 가능.
