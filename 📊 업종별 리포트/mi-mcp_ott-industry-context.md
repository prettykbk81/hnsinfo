# OTT/콘텐츠 업종 맥락

> ⚠️ 이 파일은 배경 맥락이다. 출력물에는 MCP 실시간 데이터를 사용하라.

## 이 업종에서 중요한 것

- **사용시간 점유율 = 구독 유지력**. MAU가 아닌 사용시간으로 승패를 판단한다.
- **사용자-시간 순위 괴리 ±2 이상** = 구조적 신호 (번들 허수 or 코어유저 몰입)
- **콘텐츠 1편 효과**: 스파이크 크기 + 4주 후 유지율로 측정
- **순환 구독자 23%**: 콘텐츠 따라 가입/해지 반복. 콘텐츠 공백 = 이탈
- **숏폼 vs 롱폼 시간 경쟁**: OTT의 진짜 경쟁자는 다른 OTT가 아니라 숏폼

## 구조적 변화 (2025~2026)

> ⚠️ 아래 항목 중 현재 분석 기간에 영향을 주는 것이 있으면 리포트에 반드시 언급하라.

- 티빙-웨이브 합병 추진 → 넷플릭스 대항마 형성 시도
- 넷플릭스-네이버 번들 ('네넷') → 구독자 4명 중 1명이 네이버 통해 가입
- OTT 요금 인상 추세 → 이탈률 상승 → 광고 모델 전환 가속
- 스포츠 중계 경쟁 (쿠팡플레이 F1/축구 vs 티빙 KBO/WBC)
- 숏폼 드라마 플랫폼 급성장 (DramaBox, NetShort)

## 이 업종에서 추가로 수행할 분석

Key Skills의 기본 프로세스에 더해, OTT 업종 분석 시 아래를 반드시 추가 수행한다:

### 사용시간-MAU 괴리 분석
- ranking_users와 ranking_time 순위를 교차하여 괴리 ±2 이상인 앱을 찾는다
- 괴리 양수(시간>사용자) = "코어유저 몰입" → 콘텐츠 투자 효과
- 괴리 음수(사용자>시간) = "번들 허수" → 가입만 하고 안 봄, 해지 위험

### 콘텐츠 1편 효과 측정
- MAU/사용시간 스파이크 10%+ 발견 시:
  - 스파이크 크기 계산 (전월 대비 %)
  - 4주 후 유지율 계산: (4주 후 - 스파이크 전) ÷ (스파이크 - 스파이크 전) × 100
  - +50% 유지 = "습관 형성", +10~50% = "일부 잔존", +10% 미만 = "일시적"
- 웹서치로 해당 시점의 콘텐츠명을 반드시 특정한다

### 숏폼 경쟁 체크
- 해당 OTT 사용시간 감소 + 다른 OTT도 감소 → "숏폼에 시간 빼앗김"
- 해당 OTT 사용시간 감소 + 다른 OTT는 증가 → "직접 경쟁에서 패배"
- 급상승 앱에 숏폼 드라마 플랫폼이 있으면 반드시 언급
